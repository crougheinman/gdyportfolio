Personal Expense Budgetting (PEB)

A comprehensive personal finance management application built with Angular and Firebase. This modern web application helps users track their daily expenses, categorize spending, and gain insights into their financial habits through an intuitive and responsive interface.

The application features real-time data synchronization, user authentication, expense categorization with visual icons, search and filtering capabilities, and responsive design that works seamlessly across all devices.

It also includes an AI-powered receipt scanner and voice entry (Google Gemini with OpenRouter, Groq and NVIDIA fallbacks), "Pebby" — an AI spending co-pilot — a statistics dashboard with daily/weekly/monthly trends, swipe-to-delete lists, and a runtime light/dark theme.
