Watchy

A Netflix-style movie and TV streaming app built with React 19, TypeScript and Vite, then packaged as a native Android app with Capacitor. Watchy serves a polished, dark, cinematic browsing experience with a rotating hero banner, horizontally-scrolling category rows, rich title modals, and a full-screen player.

Catalogue metadata — trending titles, a Netflix-on-TMDB row, genre rows, multi-search and trailers — is pulled live from The Movie Database (TMDB) API. Playback is served through a registry of embed providers with one-tap failover, so when one source is down the viewer simply switches to another.

The app is gated by Supabase authentication and driven by Supabase remote config: a force-update gate for stale APK builds, a global maintenance switch, and per-account disabling — all of which propagate to live clients within about a minute, no redeploy required.

Technical Features

Frontend & Mobile

  • React 19 - Modern hooks-based UI
  • TypeScript - Fully type-safe codebase
  • Vite 8 - Fast build & HMR dev server
  • Capacitor 7 - Native Android wrapper (hardware back button, splash, status bar)
  • Hand-rolled CSS - Custom dark, cinematic UI with skeleton loaders
  • Responsive Design - One codebase for phone and browser

Backend & Services

  • Supabase Auth - Email/password sign-in with session persistence
  • Supabase Remote Config - Version gate, maintenance switch, account status
  • TMDB API - Trending, genres, search and trailer metadata
  • Multi-Provider Streaming - Embed server registry with failover
  • localStorage Store - Continue Watching with cross-tab sync
  • Google Drive APK - Out-of-store update distribution

Key Features

  • Rotating Hero: Cycles the top 10 trending titles with no extra request
  • Category Rows: Trending, Netflix, Action, Comedy, Sci-Fi, Drama and Thriller
  • Instant Search: TMDB multi-search across movies and TV shows
  • Continue Watching: Resume playback where you left off, synced across tabs
  • Server Switching: Pick a working source when a provider goes down
  • Ad Shield: Blocks redirect-jacks and pop-ups while the player is open
  • Force-Update Gate: Stale builds are prompted to grab the latest APK
  • Maintenance & Account Gates: Server-controlled lockouts without a redeploy

Development Approach

This project demonstrates modern React and native-hybrid development practices including:

  • Custom Hooks: Data fetching, auth, version and account status isolated into reusable hooks
  • Provider Abstraction: Each stream source owns its own URL builder behind a single registry interface
  • External Store Pattern: Continue Watching uses a pub/sub store with referentially-stable snapshots
  • Fail-Open Config: Network/config errors never lock users out — the app keeps the last known good state
  • Defense in Depth: no-referrer frames, origin checks on postMessage, and a redirect/pop-up guard
  • Native Integration: Android back button, mixed-content handling and splash/status-bar theming

Current Status

The application is actively under development with regular updates and feature additions. The project showcases my expertise in building cross-platform streaming experiences with React, TypeScript and Capacitor, backed by Supabase for auth and live remote configuration.
